# Nhạc nền

Thư mục này **cố ý để trống**. Không có bản nhạc nào được kèm sẵn — nhạc có bản quyền là
lý do bị loại ở nhiều cuộc thi, nên chọn nhạc là việc của người làm clip.

Đặt file nhạc (mp3, wav, m4a) vào đây rồi khai trong kịch bản:

```jsonc
"brand": { "music": "ten-file.mp3", "musicVolume": 0.16 }
```

Nguồn nhạc miễn phí có thể dùng: YouTube Audio Library, Pixabay Music. Đọc kỹ điều khoản
từng bản — một số cho dùng trong video nhưng không cho phân phối lại file gốc, khi đó
**đừng đẩy file đó lên git**.

Chi tiết cơ chế trộn nhạc: mục 5c trong `HUONG-DAN-TAO-VIDEO.md`.
